## 2. 構造化出力

- スキーマは**フラット**にし、`enum` と整数を使う。「なし」は `-1` や空文字のような番兵値で表す。`oneOf` やnull許容の型は各社で対応に差があるので避けると移植しやすい。
- 受け取ったら Pydantic で再検証する。範囲外の値は丸め（clamp）、失敗したら1回だけ再試行し、だめなら安全側の既定動作（停止など）にする。
- 各社の指定方法:
  - Claude: `output_config={"format": {"type": "json_schema", "schema": ...}}`
  - Gemini: `response_format={"type": "text", "mime_type": "application/json", "schema": ...}`（Interactions API）
  - OpenAI: `text={"format": {"type": "json_schema", ...}}`（Responses API）

## 3. 安全装置（デモを止めないために）

- **止まる条件を必ず入れる:** 最大ステップ数、全体のタイムアウト、同じ行動（同じツール・同じ引数）が3回続いたら停止。
- 実機を動かす操作は範囲内に丸め、緊急停止ボタンを付ける。
- APIエラーやレート制限のときに表示する文言と、**ダミー応答で動き続けるデモモード**（環境変数で切り替え）を用意する。

---

## 4. APIキーと料金

- APIキーはバックエンドの環境変数だけに置く。フロントのコードはブラウザに配られるので、**APIキーを絶対に入れない**（Next.js なら `NEXT_PUBLIC_*` に入れない）。
- 会期中だけ使うキーを作り、上限を設定しておく。

## 5. LLM/VLM 呼び出しの共通メモ（2026-11時点）

- **評価・判定は別の呼び出しにする。** 生成や行動決定と同じ呼び出しで判定させると、自己評価が甘くなる。判定は別のプロンプトで行う。
- **思考量は速度優先で低めにする。** Claude は `effort`（low〜max。Opus 5.5 の既定は `medium`）、Gemini は `thinking_level`（low〜minimal）。
- **Claude API の注意:**
  - Opus 5.5 は思考を無効にできない。速さは `effort` で調整する。
  - `tool_choice` で特定ツールを強制（`any` / `tool`）すると 400 エラーになる。`auto` のままプロンプトで誘導する。
  - `temperature` などのサンプリング引数は送らない。
- **リアルタイムAPI（音声などの双方向ストリーミング）:** Gemini Live（`gemini-3.8-live`）、OpenAI Realtime（`gpt-realtime-2.1` など）、`gpt-live-1`。
- **カメラ・マイクは HTTPS が必要**（`getUserMedia`）。
